# Student getting-started guidance

Mode: Operate. User reports real students do not know what to do after sign-up. Keep the existing software theme and system structure; improve the path to first learning value.

THESIS: Give a new student one clear next action, backed by a short account-aware checklist.
OWN-WORLD: Existing navy surfaces, cyan actions, blue-gray text, Geist, fine borders and inline SVGs. No new assets or dependencies.
STORY: Register, find the teacher's class, join, submit the pre-test, and open the first available module/lesson. Existing prerequisites stay authoritative.
FIRST VIEWPORT: New students see a welcome with a prominent Find my class button and a three-step checklist. After joining, the guide points to pre-test; after submission, to Learning Path. Action stays above the checklist on phones. Returning students with saved learning progress see the regular dashboard, with help available from Getting started in the header.
FORM: An inline guide, not an interrupting modal. Hide/show controls, replay from the header, contextual task help and focus on the real destination. State comes from actual class, assessment and learning records, never a fake completion flag.
FINISH: Run the complete registration-to-learning fixture flow, prerequisite checks, desktop/tablet/phone layouts, replay/hide/focus and errors; build/lint, independent visual review and a short handoff. No deployment.
