# Manage Content: simple instructions

Open **Manage Content** as an administrator. The **How to use this page** guide can be expanded or collapsed at any time.

## Create learning content

1. Click **New module**. Enter its title, description, and order, then click **Create draft module**.
2. Click **New lesson**. Enter the lesson title, learning material, and order, then click **Add lesson**.
3. Open **Quiz questions** to add questions, answer choices where needed, a correct answer, and an optional explanation. Open **Practical activities** to add a test-case, bug-report, or reflection task with instructions.
4. Save your work, click **Preview**, and resolve any warnings. Open the lesson preview to review its saved content. When it says **Ready to publish**, click **Publish**.

Teachers can assign practical activities from published modules to their classes. Students follow the normal Learning Path unlocking order.

## Edit existing content

- Use **Choose module** and **Choose lesson** to select the content. Their existing details load automatically.
- Open **Module details** or **Lessons**, make changes, and use **Save module** or **Save lesson**. **Reset changes** restores that form's saved details.
- For a saved question or activity, click its **Edit** button. Save the changes, or use **Cancel edit** to return to the new-item form.
- **New module** and **New lesson** create separate items. Save your work before changing the selected module or lesson.

Changes to already-published content are saved directly. The **Published** status tells you it is already available; another publish action is not required.

## Useful details

- **Order:** lower numbers appear first, such as 1, 2, and 3.
- **Answer choices:** enter one choice per line. The correct answer must match a choice. True/false questions use a correct-answer dropdown.
- **Required for progress:** students must submit this activity before taking the lesson quiz.
- **Draft:** saved for editing. **Published:** available to students. **Hidden:** kept in the system but unavailable in the student Learning Path.
- **Preview:** checks saved content. Save changes before checking it again.
- **Hide:** use this to take a module out of the student Learning Path while keeping its content.
- **Delete:** requires confirmation and the existing dependency checks. Remove unused questions and activities before deleting a lesson, and unused lessons before deleting a module. Records associated with student work may be protected from deletion; hide the module instead.

Lesson quizzes are managed here. Pre-test and post-test understanding surveys are managed through **Research & Evidence**.
